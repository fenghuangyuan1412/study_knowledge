## 为什么选这个来源

batch-001 沉淀的是「被测项目认知 + AI 测试全景 + 入门路线」，解决「测试是什么、在往哪走」。

本批解决的是下一个问题：**「往测试开发走，具体要会什么、按什么顺序学」**。华测这份大纲的价值在于它把这条路径拆得很具体（三大自研平台 + 企业级定制 + 两条技术栈拓展线），适合当作**能力自查清单**用。

## 与 batch-001 的衔接

- batch-001 的 03「AI 测试到底测什么」把 AI 测试拆成「用 AI 辅助测试」与「对 AI 系统做测试」；
- 本批 02 是它的下一步：从「用 AI 辅助」走到「让智能体自己调用测试能力」，落到 MCP / Skill / Agent 三件套；
- 本批 01 的三级跃迁（会测 → 会自动化 → 会平台化/工程化）可以作为长期学习路线的骨架。
