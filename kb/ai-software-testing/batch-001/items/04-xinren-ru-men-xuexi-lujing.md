## 一句话摘要

面向软件测试新人与转行者的一篇路线图：先按"测试基础→计算机基础→SQL→编程语言→接口测试→Web/App 自动化→性能测试→集成测试"搭建技能树，再说明测试员/测试工程师、测试开发工程师、高级测试开发工程师/测试架构师三个等级的职责与能力要求，可作为评估"我该学什么、学到什么程度"的坐标。

## 核心内容

1. **软件测试的正确路线（按序递进）**：
   - 软件测试基础：建立测试流程整体概念，弄清测试术语与测试类型区分、测试用例的作用/本质/写法，以及测试报告、缺陷管理，认识常见工具（Selenium、Postman、禅道）。
   - 计算机基础：操作系统原理与 Linux 命令、测试基础理论、前端基础（HTML+CSS+JavaScript）。
   - SQL 数据库：增删改查、聚合函数、条件查询、子查询等基础语句；理解数据库在接口测试、性能测试中扮演的角色。
   - 编程语言：无基础推荐 Python、有基础可选 Java；Python 对后续自动化意义重大——"学好 Python 语言基础是整个自动化测试的一个开端"，后续 Web/App/接口自动化及自动化平台脚本多基于 Python。
   - 接口测试：理解 HTTP/HTTPS 协议与接口概念，掌握 Postman 操作与使用技巧。
   - Web 自动化测试：对 Web 页面做界面、数据、交互等测试，核心工具 Selenium 及环境搭建。
   - APP 自动化测试：当前较主流的测试技术方向，掌握 Appium，覆盖 Android、iOS、鸿蒙等多系统的测试方法与移动自动化环境搭建。
   - 性能测试：属高端测试技术，需掌握负载/压测工具与系统化测试思维（原文提及：会性能测试的工程师在一线城市薪资约 18-25K，为作者陈述，非标准行情）。
   - 集成测试/DevOps：掌握持续集成 Jenkins、Git 的环境部署与系统化分支管理，以及 Docker 容器的部署应用。

2. **三个等级的职责与能力（职业进阶坐标）**：
   - 测试员/测试工程师：以业务测试为主（需求分析、测试方案、测试策略、测试执行），作者对标"百度 T3/T4、阿里 P5、腾讯 T1-T2"；可能带外包团队做基础业务测试；需懂所测领域的业务知识。
   - 测试开发工程师：目前招聘多从这一档起招，核心要求是"懂研发、懂测试"，编程是硬门槛——Java、Python、shell、SQL 为基础；按能力高低分配技术/业务比例（能力强约 80% 技术 + 20% 业务，能力弱则反之，太弱则 100% 业务）；工作覆盖客户端 UI 测试、服务端接口测试、性能测试及写自动化；面试主要卡自动化与编程能力。
   - 高级测试开发工程师/测试架构师：业务测试极少甚至没有，转为负责团队流程管理、白盒测试体系、测试工具与平台开发、质量监控与质量管理；典型配置是一个团队 1 名测试管理者 + 1-2 名高级测试开发/专家，负责持续集成系统与平台搭建，并带 2-3 名测试开发工程师。

3. **配套学习体系（原文尾部广告性清单，仅取知识结构）**：Python 编程入门→接口自动化项目实战→Web 自动化项目实战→App 自动化项目实战→测试开发 DevOps 体系→常用自动化测试工具→JMeter 性能测试。注意：原文为营销向文章，其中"一线大厂简历"等内容与广告相关，参考知识结构即可。

## 与学习目标的关系

- 本知识库主线是"利用 AI 加速软件测试"，而本文提供了这条主线的基础设施：测试流程、用例、缺陷管理、接口/Web/App 自动化、性能与 CI 等环节，正是 AI 工具（写计划、生用例、补断言）要嵌入的落点——先按路线把每个环节的基础打牢，再用 AI 提速，效果可度量（可对照同批笔记 03 的"三阶段"成熟度模型）。
- "被测项目认知"层面：黑马头条这类被测项目涉及的登录、文章审核等业务，对应的正是接口/Web/自动化测试技能的练兵场。
- 等级说明提示进阶方向：AI 能力更多在"测试开发/测开工程师"及以上等级产生价值，新人不必一上来就追大模型，先具备被 AI 增强的领域能力。
