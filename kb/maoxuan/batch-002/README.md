## 为什么做这一批

batch-001 只精读了 5 篇代表作，向量库里可检索的内容太薄——问本地模型毛选相关问题，它只能给个大纲，答不出具体内容。

本批把**第一卷 18 篇逐篇做结构化内容总结**入库，让本地模型在回答时能检索到每篇的写作背景、主要论点、关键提法和原文引句，从而给出有依据的回答。

## 生成方式（可复现）

- 脚本：`web/.runtime/_mao_sum/summarize.py`（本地模型 map-reduce + 断点续跑）
- 模型：本地 Ollama `qwen3.5:9b`（`num_ctx=8192`，`think=false`）
- 流程：长文按 2400 字切块 → 每块提炼要点 → 汇总要点合成结构化总结
- 原文来源：《毛泽东选集》1–7 卷全文语料（本地 skill `mao-selected-works`，**不入 git**）
- 复现：`python web\.runtime\_mao_sum\summarize.py --volume 1`

> **重要**：本批是**内容总结**（依据原文分段归纳），**不是原文全文**。需要引用原文时请回原书或本地全文语料核对。

## 条目结构

每条统一为：

```
frontmatter（title / source_url / year / tags / batch=2）
## 一句话摘要
## 写作背景与针对的问题
## 主要内容
## 关键概念与提法     ← 词条 + 原文原句照抄，不自行解释
## 结论与影响
## 短句引文           ← 原文原话，可回原书核对
## 来源
```

设计取舍：**「关键概念」只照抄原文相关句、不自行释义**。早期版本让模型解释词义，出现了把「管公堂」误解为司法机构之类的臆测；改为「词条 —— 原文原句」后杜绝了这类编造，原文没有对应句子时明确标注「（提要未涉及）」。

## 与 batch-001 的关系

- `batch-001`（5 篇）：**精读层**——5 篇代表作的「背景 + 要点 + 解读」，侧重方法论迁移到学习与工作。
