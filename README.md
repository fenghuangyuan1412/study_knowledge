# 个人学习知识库

> **v1.0**（2026-09-16）· 版本记录见 [`CHANGELOG.md`](CHANGELOG.md) · 方向与约定见 [`agent.md`](agent.md)

把学习内容按主题组织、沉淀为 Markdown，再向量化成本地可检索、可问答的知识库。
每条内容尽量带出处，配合「可溯源检索」能力，引用可回原文核对。

**本地优先、离线可用**：知识内容、向量库与模型都放在自己的机器上，不依赖云服务；
也便于打包分享给他人自部署。

> 每个知识库在自己的目录下有一篇 `README.md`，写明该库的简介、内容组织与学习路线。

## 主要特性

- **三级自动降级问答**：RAG 生成式 → 语义检索 → 关键词检索；模型服务不可用时仍能查得到
- **引用可溯源**：回答附知识库引用片段，可回原文核对
- **本地模型**：嵌入（bge-m3）与对话（qwen）由本机 Ollama 承载，零云 API 依赖、零按量费用
- **多知识库**：每个库是独立数据实例，页面顶部一键切换
- **手机可用**：问答页为 PWA，手机浏览器「添加到主屏幕」即成为全屏 App
- **公网可访问**：隧道穿透 + 口令鉴权，另有按 IP 限流与生成并发保护
- **可容器化**：`Dockerfile` + `docker-compose.yml`，可部署到虚拟机、云服务器或宝塔面板

## 快速开始

```powershell
# 本机启动问答服务，然后打开 http://127.0.0.1:18765
powershell -ExecutionPolicy Bypass -File web\run.ps1 -Action start
```

## 内容约定

- **Markdown 是知识的唯一事实来源**：按 `kb/<方向>/batch-<编号>/items/` 组织，经 git 版本管理；
- **方向性 / 结构性改动**先在 `agent.md` 约定，再动代码；具体内容增删改直接改对应知识库的 Markdown；
- **版权文本与大语料留在本机**，不入版本库；公网只暴露 Web 问答层，《毛选》1–7 卷全文不在公网链路上；
- 详情见 [`agent.md`](agent.md) 第三、四节。
